# 使用说明

面向装好之后的日常使用。每一组设置做什么、每个选项的实际效果、以及配不上的时候怎么排查。

> 安装与构建看 [README](../README.md)。实现细节看 [ARCHITECTURE](ARCHITECTURE.md)。

---

## 1. 第一次打开

装完并设为默认桌面后，按 Home 会进到首页。此时大概率是「能看但不能用」的状态：

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 左半边一片空白 | 没选地图应用，或地图没装 | 设置 → 地图 → 当前地图 |
| 音乐卡显示「暂无播放」 | 没有播放器在播 | 打开 md3Music 放一首 |
| 音乐卡有歌名但没歌词 | 播放器没开歌词转发 | 设置 → 媒体 → 歌词，会有提示 |
| 天气卡显示「点此填 Key」 | 没配和风 | 设置 → 天气，见第 6 节 |
| 状态栏右上信号是斜杠 | 车机走私有信号通道 | 平台限制，无法修 |

### 第一次进桌面会弹权限

这是**故意的一次性引导**：装完第一次进桌面，会把需要的东西一次要齐，之后永久不再打扰。

| 申请的东西 | 用途 | 拒绝了会怎样 |
|---|---|---|
| 位置（系统弹窗） | 天气卡按定位自动换城市 | 只能在设置 → 天气里手工选城市 |
| 电话（系统弹窗） | 状态栏信号格数 | 信号格显示斜杠 |
| 显示在其他应用上层（跳系统页） | 给悬浮高德补圆角遮罩 | 地图卡四角变直角，别的功能照常 |

第三个会有个自己的说明框，点「去开启」跳到系统页；点「暂不」也行，不影响使用。

**当时点了拒绝怎么办**：设置 → 权限，那里会写「缺 电话」这类，点一下重新弹框。如果系统已经不给弹了（"不再询问"），会直接带你去应用信息页手动打开。

**进设置的两个入口**：右上角齿轮，或应用列表第一格的「桌面设置」。底栏关掉时齿轮还在，不用担心进不去。

## 2. 桌面操作

| 操作 | 结果 |
|---|---|
| 左右滑动 | 首页 ↔ 应用列表 |
| 点时间日期卡 | 打开系统日期时间设置 |
| 点音乐卡（封面/歌名） | 打开播放器 |
| 点天气卡 | **刷新**天气；没配好则直接弹配置框 |
| 点地图区 | 按设置打开地图（直接打开导航 / 悬浮） |
| 长按地图区 | 进设置（地图区空白时的兜底入口） |
| 长按应用图标 | 应用信息 / 卸载 |
| 长按状态栏 WiFi 或蓝牙 | 进系统对应的设置页 |

## 3. 状态栏

顶栏从左到右：**快捷应用 · 时间日期（居中） · 信号 · WiFi · 蓝牙 · 齿轮**

### 快捷应用（左上角）

设置 → 外观 → 状态栏快捷应用。

- **开关关着**：只显示一个「···」，点了进设置
- **开关打开但没选**：同样显示「···」，点了直接进选择页
- **选了 2~5 个**：按你排的顺序从左到右铺开

选择页（设置 → 外观 → 选择快捷应用）里每个已选项右侧有 `↑ ↓ ✕`，`↑↓` 调序、`✕` 移除。列表顺序就是左上角的显示顺序。

> 间距按「一排独立入口」而不是「挤在一起的一组」来定。图标最多 5 个，再多就会挤到时间上。

### 信号 / WiFi / 蓝牙

三个图标都是三态的，看图就能判断状态：

| 图标样子 | 含义 |
|---|---|
| 实心加粗 | 已连接 |
| 带问号 `?` | 已开启但没连上 |
| 红色叉 | 已关闭 |
| 斜杠 | 读不到（平台不给数据） |

单击是**真的开关**，不是跳设置页。切换有 700ms 防抖，连点不会来回抖动。

## 6. 天气配置

需要自己去 [console.qweather.com](https://console.qweather.com) 注册（个人免费额度够用）。**安装包里不含任何密钥。**

### 方式一：API KEY

1. 控制台 → 项目管理 → 创建项目，拿 **API KEY**
2. 同一页面顶部复制 **API Host**，形如 `abc1234xyz.re.qweatherapi.com`
3. 车机上：设置 → 天气 → 和风 Key → 两个字段都填

> **API Host 必须填**。新版和风没有可用的公共域名，不填会 `Invalid Host` / 403。
> 老账号（2024 年前注册）可以留空，会走 `devapi.qweather.com`。

### 方式二：JWT

新项目已经不给 API KEY 了，只能走 JWT。它只替代 URL 里的 `&key=xxx`，换成 `Authorization: Bearer`，**请求仍然打到你的专属域名，API Host 照样要填。**

1. 控制台 → 项目管理 → 创建凭据，拿 **Project ID**、**Key ID**、**Ed25519 私钥**（整段 PEM，含 `-----BEGIN PRIVATE KEY-----`）
2. 车机上：设置 → 天气 → 认证方式选 JWT → JWT 凭据 → 三项都填

私钥很长，在车机上手打不现实，用下面的手机导入。

### 手机导入（两种方式都支持）

任一张输入框里点「**用手机填**」：

1. 车机会起一个临时页面，显示一个网址和 4 位 PIN
2. 手机连同一个 WiFi，浏览器打开那个网址
3. 填完点「保存到车机」，车机立刻收到

页面 **2 分钟过期**，填错 PIN 会拒绝。这是局域网明文 HTTP，只在配置那两分钟开着，**别在公共 WiFi 下用**。

留空的字段 = **不改动已存的值**，不会把配置清掉。

### 定位与地名

打开「城市跟随定位」后，卡片显示两级地名：

```
枣庄 市中          22:34
枣庄 薛城          22:34
```

市名大一号，区名小一号且淡一档。两区之间温度可能差 2℃，所以区分到区是有意义的。

**精度到区/县/县级市这一级**。手填城市名时不显示区名（本来就没定位）。港澳显示如「澳门 花王堂區」。

### 排查

| 提示 | 原因 |
|---|---|
| `Invalid Host` | API Host 没填或填错（新账号最常见） |
| `HTTP 403` | Key 与 Host 不配对，或控制台「应用限制」里的 IP/域名没保存 |
| `查城市失败` | 网络不通，或定位没拿到坐标 |
| 卡片有数但设置页验证失败 | 正常，两者走同一条路，若不一致说明旧版本，升级即可 |
| 温度对但地名是上级市 | 你在县或县级市，和风只回区县名、没有级别标记，无法可靠区分，见 ARCHITECTURE |

## 7. 音乐与歌词

歌词来源是**播放器主动发布会话**，不是桌面去抓。

前提两条：
1. 装 md3Music，并且它是当前播放器
2. md3Music 设置里打开「**歌词转发**」

满足后：歌名、歌手、封面、时长、进度、**逐句歌词**全都有。不满足则只有歌名和封面。

### 先开桌面、后开音乐也能自动接上

桌面是 HOME，开机就起来了，那时 md3Music 多半还没被点开。它的媒体会话**只在真正播放时才创建**，没播歌时连接会被它直接拒掉（日志里是 `Session rejected`）。

所以顺序不影响使用：

1. 桌面先起来 → 卡片空着，后台按 `1s / 2s / 3s / 5s / 10s` 的节奏一直重试
2. 你打开音乐、点播放 → 几秒内桌面自己接上，歌名、封面、歌词一起出来
3. 从音乐 App 切回桌面时还会**立刻**再试一次，不用等下一轮

不用重进桌面。卡片空着的时候点播放键，也会直接把音乐 App 拉起来。

### 长歌词怎么显示

一句歌词放不下时，它会**在停留时间内从左扫到右，停在句尾**，换句时重新开始。不会来回反复扫（那样一句只有 2~3 秒根本扫不完）。

暂停时动画停住，继续播时接着扫，不会跳回开头。

### 显示「未连接播放器」

大多数情况是 `MediaController` 没绑上会话。**先把桌面划掉重开**（或重启桌面），它会重新绑。这是模拟器和部分车机的老毛病，与音乐卡本身无关。

## 8. 底栏与音乐控件的关系

底栏（底部那条带封面、歌名、三个控制键的横条）显示时，音乐卡里**只有歌词和进度**，没有重复的控制键。

把 设置 → 外观 → 显示底部导航 关掉后：

- 底栏消失，它占的那条高度还给内容，音乐卡变高
- 音乐卡里**自动出现 ⏮ ▶ ⏭**，播放键是蓝底圆形
- 实测歌词从 5 行变 7 行，一行不少

这样无论底栏开还是关，你都有一处能控制播放，且不会有两处。

## 9. 均衡器

设置 → 音效 → 调整均衡器。

| 元素 | 作用 |
|---|---|
| 顶部曲线 | 31 段响应的连线，横轴 20Hz ~ 20kHz |
| 推子 | 拖动调整某一频段增益，范围 ±12dB |
| **双击推子** | 弹数值输入框，31 段挤在一起时靠这个精确定位 |
| **点推子下方的频点数** | 改这一段的中心频率（20Hz ~ 20000Hz）。改过的会显示成蓝色 |
| 底部预设 | `预设` `平直` `车机矫正` `自定义` |
| 前级 | 整体增益，≤0dB，用来给提升段留 headroom，防止削波 |
| 全部归零 | 只清增益，频点不动 |
| 标准频点 | 31 个频点复位回 1/3 倍频程网格，增益不动 |

**内置「车机矫正」**：由 20 点实测频响拟合到 31 段，最大 +1.4 / 最小 −2.2 dB。它的用途是把车机频响拉平，**本来就该听不出明显变化**——想听效果请自己把低频推子拉上去。

### 频点也能改

默认 31 段是 1/3 倍频程网格（20 / 25 / 31.5 … 20000）。点推子下方任意一个频点数字就能改这一段的中心频率：

- 可输入范围被夹在左右邻居之间（各留 1% 间隙），**改一段不会挤动别的段**
- 想在某处加密（比如人声区多要几段），先把边缘的段往外挪，再把目标段往里挪
- 套用预设会连频点一起复位——内置曲线都是按标准网格拟合的，频点挪走后那条曲线就不成立了
- 段数固定 31，不能增删（系统 API 的段数在构造时定死，改段数要重建 effect）

### 生效范围

挂在 `session 0`（全局输出混音）上：

- 桌面、音乐、视频、导航的**声音都会经过它**
- 收音机（FM/AM）不经过 —— 那是独立硬件通路
- 手机蓝牙音乐要看车机怎么接的，部分车机不经过 Android 混音

### 两个必须知道的点

1. **和 FreeBand 不能同开**。控制权排他，后开的抢前一个，表现是「调哪边都不对」。
2. **验证方法只有一个**：放首歌，把 62Hz 推到 +12，**用耳朵听**。界面显示什么、`dumpsys` 里有没有 effect，都不算数。

### 曲线存哪、什么时候落盘

存在本机 `SharedPreferences`。拖动时实时下发但**不写文件**，松手才落盘（避免每秒几十次写盘）。所以拖到一半杀掉 App，曲线会回到拖之前的值。

## 10. 常见问题

**改了设置没反应？**
绝大多数设置是即时生效的。个别需要重建界面的（如首页布局），退出设置页返回时会自动重排。

**桌面被系统杀了 / 回到原厂桌面？**
车机上「一键清理」类工具可能杀掉桌面进程。去系统设置里把 CarLauncher 加入白名单，或确认它仍是默认桌面。

**重启后设置都还在吗？**
在。全部存在本机 `SharedPreferences`。

**能装到手机上吗？**
技术上能，但布局是为车机横屏设计的，窄屏会很难看。`minSdk` 是 28。

**为什么天气要自己申请 Key？**
把 Key 写进 APK 等于公开，任何人都能抓包拿去刷额度。所以设计成用户自备。

**地图区一直显示「已请求 高德地图 显示悬浮窗」？**
说明用的是官方版高德，它没有悬浮窗。改用「直接打开导航」模式，或换悬浮修改版地图。

**夜间模式下了，高德地图还是白的？**

先确认三件事：

1. **开关开着吗** —— 设置 → 地图 → 「高德日夜跟随桌面」，默认是开的
2. **装的是车机版吗** —— 只有 `com.autonavi.amapauto`（高德地图车机版）响应这套协议。手机版、车镜版（`amapautolite`）都不行
3. **版本够吗** —— 需要车机版 1.4.2 以上

都满足却还是白的，说明这个改版高德把协议裁掉了，目前没有别的办法——只能进高德自己的设置里把日夜模式设成「黑夜」（代价是白天也黑），或者换回官方车机版。

> 为什么不走系统深色模式？因为高德车机版 `targetSdk=23`，不参与 Android 10 起的系统深色模式；而桌面的日夜是本进程内的 `uiMode` 覆盖，改不到别的 App。两边唯一的连通路径就是这套广播协议。

**手动改高德的日夜会怎样？**

只要桌面重新回到前台（或系统日夜变了），就会再推一次把高德纠回来。想彻底不管，把「高德日夜跟随桌面」关掉即可。

**导航时地图不居中 / 右边被裁 / 缩放太大？**

高德在这个悬浮窗里刚进入导航那一帧会把视口算错，三种症状是一起出现的。可以这样处理：

1. 点一次高德的「全览」再让它自己回到导航 —— 立刻正常（这是验证问题的快捷方式）
2. 桌面开着「开始导航时校正地图视口」（默认开）—— 进入导航时自动抖一次，等价于第 1 步
3. 导航途中又偏了 —— 设置 → 地图 → 「立即校正一次」

万一自动那步没起作用，抓一下日志：

```bash
adb logcat -s AmapNavGuard:I AmapPlus:I
```

- 出现 `导航/巡航开始` + `nudge 触发` 但画面没变 → 高德这次没被抖醒，手动点「立即校正一次」
- 连 `导航/巡航开始` 都没有 → 这个改版高德不发 `AUTONAVI_STANDARD_BROADCAST_SEND`，自动校正用不了，只能手动
