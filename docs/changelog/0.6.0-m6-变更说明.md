# 0.6.0-m6 变更说明

构建：`app-debug.apk`（versionCode 6 / versionName 0.6.0-m6）· 2026-11-01
验证环境：雷电实例 `adbtest`（Android 9 / API 28 / 1920×1080 / dpi 240）

## 一、地图卡现在有圆角了

地图是高德自己建的 `TYPE_APPLICATION_OVERLAY` 窗口，矩形永远是方的，把卡片的 18dp 圆角
整个盖住。任何只作用于「自己 View 树」的手段（`clipToOutline`、`ViewOutlineProvider`、
`Window.setBackgroundDrawable`）都碰不到别人的窗口。

### 先试了让高德自己画（失败）

一口气发了 8 个候选 extras：`radius` / `corner` / `cornerRadius` / `corner_radius` /
`round` / `roundRadius` / `rx` / `r`，值都是 48。结果 `mAttrs` 和截图四角**完全没有变化** ——
它只读 `x` / `y` / `w` / `h`。这条路可以直接放弃。

### 最终方案：在它上面盖一层不可触摸的遮罩窗口

新增 `map/MapMaskOverlay.kt`，是与卡片矩形等大的第二个 `APPLICATION_OVERLAY` 窗口，
只负责「卡片形状以外」的像素：

| 区域 | 内容 |
|---|---|
| 四角楔形 | 桌面背景（壁纸 + scrim），逐层画进遮罩位图 |
| 一圈细边 | 卡片自己的 `bg_map_placeholder`（保留 18dp 圆角 + 1dp 描边） |
| 中间 | 全透明，地图从下面透出来 |

窗口带 `FLAG_NOT_TOUCHABLE`，所以地图照样能拖、能缩放（已实测）。

## 二、三个踩过的坑（都写在代码注释里了）

1. **角上不能填卡片色。** 卡片 drawable 自己是圆角的，圆角外面它根本不落笔。就算强行
   填成卡片底色，角上还是一个方块、只是变暗，看着仍是直角。必须填**背景**才是"角被切掉"。
2. **背景不是一张图。** 桌面背景 = `wallpaper_bg`（可能是系统壁纸，`centerCrop`）+ `wallpaper_scrim`（#40000000）。
   只画壁纸会偏亮：实测楔形 `(8,10,14)`、真实背景 `(6,7,10)`。改成按层把两个 View 依次 `draw()`
   进遮罩位图后，右下角 `(12,17,25)` == 真实背景 `(12,17,25)`，左上差 1/255。
3. **不能用 `clipPath`。** 这台设备上非凸路径裁剪之后什么都不剩（整块填红能画出来，裁剪后变全空）。
   改成「画进位图 → `PorterDuff.CLEAR` 挖洞」，逐像素运算，不依赖路径裁剪实现。

## 三、z 序与生命周期

- 跨应用同层级窗口的 z 序由系统按加入先后决定，高德窗口可能比我们晚建 →
  `show()` 会在 450ms 后移除重加一次。实测 `dumpsys` 里 `MapCornerMask` 稳定在 Window #1、
  高德浮窗 #2。
- 几何没变不重建（早期版本 1 秒内加了 12 次，会闪）。
- 切页 / 退出 / 悬空时 `hide()`；回到首页重新 `show()`。

## 四、实测结果

| 场景 | 结果 |
|---|---|
| 首页 | 四角圆角，弧线与 1dp 描边接上；遮罩 #1、高德 #2 |
| 拖动地图 | 画面跟随（触摸穿透成功） |
| 点缩放 −/+ | 缩放生效 |
| 滑到应用页（从右侧卡片起手） | 高德窗口与遮罩都归 0 |
| 滑回首页 | 两者都回来，遮罩仍在上层 |
| 崩溃 | 0 |

## 五、限制

1. 遮罩只能"遮"不能"裁"：高德窗口本身仍是方的，靠四个楔形盖住。若高德自己弹出自绘浮层
   超出卡片矩形，会露在遮罩下面。
2. 楔形取的是我们这一侧背景 View 的像素。若以后换成动态壁纸/视频壁纸，颜色可能对不上
   （静态壁纸、系统壁纸都没问题，因为都是让 View 自己走一遍绘制）。
3. 地图区起手滑动仍会被高德吃掉，切页要从右侧卡片或底栏起手 —— 浮窗方案的固有限制，未变。
