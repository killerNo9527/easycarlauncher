# 0.9.15-m25 · 状态栏做成真控件（信号 / Wi‑Fi / 蓝牙 / 设置）

> 版本：0.9.15-m25（versionCode 25）
> 上一版：0.9.14-m24

## 一、改了什么

状态栏右侧原来什么都没有，只能看时间。现在四个图标都是**能读状态、能点、点了会改系统设置**的控件：

| 图标 | 单击 | 长按 | 三档状态 |
|---|---|---|---|
| 信号格 | 打开系统「无线和网络」设置（没有电话权限时先申请） | — | 真实 4 档信号（读不到 = 斜杠） |
| Wi‑Fi | 开 / 关（真实调用系统开关） | Wi‑Fi 设置页 | 已连接 = 加粗；已开未连 = 带「?」；已关 = 斜杠 |
| 蓝牙 | 开 / 关（真实调用系统开关） | 蓝牙设置页 | 同上 |
| 设置（齿轮） | 进桌面设置（和底栏那个齿轮同一个入口） | — | — |

视觉上把三个连接类图标统一成一套描边语言；齿轮换成了线条版（原来那个实心齿轮在 26dp 下会糊成黑块，和旁边三个描边图标差得太远）。信号格是自绘的 4 根圆角柱，档位来自 `SignalStrength.getLevel()`，不再是一张静态图。

## 二、几个关键实现决定

**1. 图标三态用三份矢量文件，不是代码改描边**
`VectorDrawable` 不支持运行时改 `strokeWidth`，所以「已连接」那档单独出一份笔画 2.7 的文件，未连接 1.85、关闭 1.9。透明度再用 `view.alpha` 叠一层（已连 1.0 / 未连 0.72 / 关 0.5），保证在车上一眼能分出三档。

**2. 点击必须防抖**
上一版实测里出现过「点一次 Wi‑Fi 图标，`WifiService` 收到两次 `setWifiEnabled`」——一次开一次关，用户看到的就是"点了反而关了"。现在两处保护：
- 同一个图标 700ms 内只接受一次点击；
- 系统正处于 `ENABLING / DISABLING`（或蓝牙 `TURNING_ON/OFF`）时忽略点击并提示"正在切换"。

**3. 系统不给改的时候不装成功**
`setWifiEnabled()` / `BluetoothAdapter.enable()` 返回 false（有的车机把开关锁在设置里），就直接 Toast 说明并把人送到系统设置页，而不是弹一句"已开启"然后图标一动不动。

**4. 信号格不糊弄**
`READ_PHONE_STATE` 是危险权限，桌面是开机自启的 HOME，不能一启动就弹权限框，所以只在用户点信号图标时申请一次；没授权就画成灰色 + 斜杠，不拿"满格"充数。

## 三、权限

新增（前五个都是 normal，装包即得）：

```
ACCESS_WIFI_STATE / CHANGE_WIFI_STATE / ACCESS_NETWORK_STATE
BLUETOOTH / BLUETOOTH_ADMIN
READ_PHONE_STATE        ← 危险权限，只在点信号图标时申请
```

## 四、实测（雷电 Android 9 / 1920×1080@160dpi）

```
StatusTray: wifi state=linked          ← 已连接 → 加粗
StatusTray: bt state=on                ← 已开未连 → 带「?」
StatusTray: signal level=4 available=true

点齿轮   → com.lf.launcher/.settings.SettingsActivity
点信号   → com.android.settings/.Settings$NetworkDashboardActivity（无线和网络）
点蓝牙   → BluetoothManagerService.enable/disable，state ON → OFF → ON，图标跟随
```

蓝牙是真点出来的：一次点击只产生一条 `tap bt current=…` 日志，状态机切换一次，说明防抖那层生效了（不再是"点一次变两次"）。

## 五、还需要在实车上确认的两件事

1. **信号格**：车机首次点信号图标会弹 `READ_PHONE_STATE` 授权框，允许后才显示档位；如果车机的蜂窝模块走私有通道（和瞬时功耗那次一样），这里会一直是斜杠。
2. **Wi‑Fi / 蓝牙开关**：部分车机把这两个开关锁在系统设置里，此时点击会自动跳到系统页面（这是设计好的降级），而不是直接切换。
