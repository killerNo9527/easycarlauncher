# 0.9.4-m14 状态栏空间回收 + 左右互换布局 + 清理地图调试项

## 1. 关掉桌面状态栏后空间没释放 —— 已修

**原因**：`map_host` 和右栏容器的 `layout_marginTop` 写死成 `@dimen/status_bar_height`
（大屏档 52dp）。状态栏一关，View 只是 `GONE`，这 52dp 的间距还留着，顶上就是一条空带。

**改法**：`HomeFragment.applyHomeFrame()` 里按状态栏显隐算顶部间距：

- 状态栏开着 → `status_bar_height`（和以前一致）；
- 状态栏关掉 → `content_padding_end`（大屏 24dp），跟左右边距一致，整块内容就是一个等边距的框。

顺带把**底栏**也修了同一类问题：底栏关掉时 `view_pager` 的 `bottomMargin`
从 `pager_bottom_inset` 归 0，不再在底下留一条给「不存在的底栏」让位的空带。

实测地图广播坐标：状态栏开 `Rect(24,52…)` → 关 `Rect(24,24…)`，
底栏关掉时下边界也从 960 延到 1056 —— 空间是真的还回去了。

## 2. 首页布局：只剩两种，左右互换，比例不变

原来的四项（Classic 经典 / 音乐大卡片 / 现代简约 / 兼容原车）本来就是占位，全部删掉，
只留两种真实布局：

| 选项 | 值 | 效果 |
|---|---|---|
| **左图右乐**（默认） | `map_left` | 地图在左（8），卡片列在右（2） |
| **左乐右图** | `map_right` | 地图在右（8），卡片列在左（2） |

- 比例不动：卡片列仍是屏宽 22%，地图吃掉剩余宽度（≈ 8 : 2）；
- 实现用 `ConstraintSet`：每次从 `fragment_home.xml` 重新 clone 再改约束，
  反方向切换不会残留上一次的约束（`clear` + `connect`）；
- 切换立即生效：设置页选完回桌面，`HomeFragment.applySettings()` → `applyHomeFrame()` 重排，
  布局变化再触发布局监听重发 `showmap`，地图悬浮窗跟着换边（实测 `Rect(24,52…)` ↔ `Rect(458,24…)`）；
- 老版本存着 `classic` / `music_card` 等值的，设置页一律显示默认项（`SettingsAdapter` 加了回退），
  不会出现「右侧显示一串原始 key、弹窗里一个都没选中」。

## 3. 删掉地图的调试开关

地图分组里只保留真正有用的四项：**当前地图 / 地图自启动 / 不绘制地图区边框 / 边框颜色**。

删除：

- 「悬浮窗坐标全传 0」开关（集成期排查位置用的）；
- 「showmap 广播探测」信息项（静态探测结论已写进代码注释）；
- 「为什么探测显示无静态接收者也能用」说明项；
- 「高德广播探针」「嵌入可行性探针（历史）」两个入口，及其 Activity、清单条目、
  整个 `probe/` 包（`AmapSignalActivity` / `EmbedProbeDemoActivity` / `EmbedProbe` / `ProbeOverlay`）。

## 4. 验证

- 状态栏开 / 关：地图卡与右栏首卡顶边始终齐平，关掉后间距 52dp → 24dp，四周等距；
- 左图右乐 ↔ 左乐右图：双向切换各一次，无残留约束、无重叠、比例不变；
- 设置页：首页布局弹窗只剩两项且能即时生效；地图分组只剩四项；
- 无崩溃，地图悬浮窗随布局换边。

## 5. 注意

- 「左乐右图」下，音乐卡在左侧窄列（和原来右栏同宽），内容与之前一致；
- 顶部间距用的是 `content_padding_end`，如果你更想让卡片**完全贴顶**（0dp），
  改一个数就行，说一声我改。
