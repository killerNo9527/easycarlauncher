# 0.5.0-m5 变更说明

构建：`app-debug.apk`（versionCode 5 / versionName 0.5.0-m5）· 2026-10-31
验证环境：雷电新实例 `adbtest`（Android 9 / API 28 / 1920×1080 / dpi 240）

## 一、底栏：红心 → 上一首

红心删掉了，中间那一组现在是 **|◀ ▶ ▶|**。

原因是 md3Music 没有任何可用的收藏写接口（详见 `md3Music-收藏接口调研.md`）：

- 它的 MCP 文档原话：酷狗开放接口**无单曲收藏写端点**，故未实现收藏工具，"收藏/取消收藏请在 App 内操作"；
- `favorites_repository.dart` 里收藏只写本地 SharedPreferences（`favorite_songs[_uid]`，上限 500 条），不对外暴露；
- `MD3MusicMediaSessionService.kt` 没有 `onCustomCommand` 的收藏分支。

也就是说，红心无论怎么实现都只能是"点了变红但实际没收藏"的假状态，所以直接换成标准上一首。

## 二、修：底栏左侧封面一直是空的

`renderMusic()` 里卡片封面和底栏封面共用同一个 `lastArt` 缓存做去重：

```kotlin
if (snap.albumArt !== lastArt) { lastArt = snap.albumArt; albumCover?.setImageBitmap(...) }
if (snap.albumArt !== lastArt) bottomArt?.setImageBitmap(...)   // ← 永远为 false
```

卡片先消费掉这次变更，底栏那次比较必然相等，所以底栏永远停在占位色块。已拆成
`lastArt` / `lastArtBottom` 两份缓存。

## 三、试过并撤回：MCP 数据通道

曾经写过 `McpMusic`（连 `127.0.0.1:17888/mcp`，用 `md3_get_player_state` +
`md3_get_lyric(hash)` 取状态和歌词），现在**整条撤掉**，代码、设置项、`MCP_BASE`
调试键、`network_security_config.xml` 全部删除，桌面只走 MediaSession 一条路。

撤回原因（都是实测出来的，不是猜）：

1. **默认关闭**：MCP 服务要在音乐 App 里「设置 → 应用与管理 → AI 代理 → 启用」，
   车机上让用户去开一个调试开关不现实；
2. **明文 HTTP**：服务是 `http://`，targetSdk 28 默认禁明文，为它单独开了回环白名单；
3. **调试也不通**：本机 `adb reverse tcp:17888` 反代建立后设备侧连不上，
   只能改成直连宿主机内网 IP 才能验，属于"能测但线上不可用"。

而 MediaSession 这条路已经实测能拿到歌名、歌手、封面、播放状态、进度和歌词时间轴
（截图验证过《只若初见》5 行歌词正确滚动），没有替换的必要。

## 四、设置页顺带清理

- 删除临时的「MCP 数据通道」状态项。

## 六、仍然存在的限制

1. 地图区起手滑动会被高德浮窗吃掉触摸，得从右侧卡片或底栏起手切页 —— 浮窗方案的固有限制；
2. 广播唤不醒未启动的高德，卡片保留「若未出现，点按这里启动一次」提示；
3. 地图底部约 60px 深色带是高德自己画的边，未做补偿。
